# Plan 2 — Web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Web UI local (FastAPI + Alpine.js) đủ 4 khu Nguồn / Xem trước / Tuỳ chọn / Chạy + quản lý preset, dùng lõi `vvb` (Plan 1).

**Architecture:** `web/server.py` (FastAPI, 127.0.0.1, token cookie, kiểm Host/Origin) → `web/state.py` (AppState: job hiện tại, EventBus → WebSocket, settings, preview) → routers `web/api/*`. Frontend tĩnh trong `web/static` (không build step): Alpine store + component JS, CSS tokens từ ui-ux-pro-max.

**Spec:** `docs/superpowers/specs/2026-10-03-video-variant-builder-design.md` mục 1.1, 1.2, 4.

## Global Constraints
- Chỉ bind `127.0.0.1`; mọi `/api` + `/ws` cần token (cookie `vvb_token` HttpOnly SameSite=Strict hoặc header `X-VVB-Token`); Host phải là `127.0.0.1:<port>`/`localhost:<port>`; Origin (nếu có) cùng host.
- Không dùng CDN lúc chạy: Alpine, icon Lucide, font Fira tự host trong `web/static/vendor|fonts`.
- Không emoji làm icon; mọi chuỗi qua `i18n/vi.json` (+ `en.json`).
- Token màu theo bảng design 4.1; contrast ≥ 4.5:1; focus ring luôn hiện; `prefers-reduced-motion`.

## API
| Method | Path | Mô tả |
|---|---|---|
| GET | `/api/system` | ffmpeg, encoder, phiên bản, settings |
| GET/PUT | `/api/settings` | theme, lang, recent, last_job |
| GET | `/api/fs/roots`, `/api/fs/list?path=` | duyệt thư mục |
| POST | `/api/fs/dialog` | hộp chọn gốc của OS (tkinter) |
| GET | `/api/presets`, `/api/presets/{id}` | danh sách / nội dung |
| PUT/DELETE | `/api/presets/{id}` | lưu / xoá preset người dùng |
| POST | `/api/presets/validate` | kiểm tra, trả lỗi theo trường |
| GET | `/api/schema` | JSON schema Preset (form tự sinh) |
| POST | `/api/project/resolve` | tự nhận slot từ thư mục dự án |
| POST | `/api/plan` | quét+ghép (probe=false) hoặc pre-flight đầy đủ (probe=true) |
| GET | `/api/media?path=` | MediaInfo |
| POST | `/api/preview/frame` | PNG 540p (header X-Duration) |
| POST | `/api/preview/clip` | MP4 xem thử 5s → `/api/preview/file/{name}` |
| POST | `/api/jobs/start|pause|resume|cancel|retry` | điều khiển |
| GET | `/api/jobs/current`, `/api/jobs/unfinished?out=` | trạng thái, job dở |
| POST | `/api/jobs/resume`, `/api/system/open`, `/api/system/quit` | |
| WS | `/ws` | snapshot đầu + sự kiện job/task/task_progress/progress/log |

## Tasks
1. **Server + state + bảo mật** — `web/server.py`, `web/state.py`, `web/api/*.py`; test `tests/web/test_api.py` (từ chối thiếu token/Host lạ, fs list, presets CRUD, plan trên `project_a`, preview frame PNG, job start→done qua WS).
2. **Vendor assets** — `scripts/vendor_assets.py` tải Alpine, Lucide SVG → sprite, Fira woff2 (latin/latin-ext/vietnamese) vào `web/static`.
3. **Khung UI + tokens + theme + i18n** — `index.html`, `css/*`, `js/app.js`, `js/i18n.js`.
4. **Khu Nguồn** — hộp duyệt thư mục, thẻ slot, bảng ghép (sửa tay, tick nhóm/clip).
5. **Khu Xem trước** — preview debounce 300ms, region editor SVG 8 tay nắm + bàn phím + ô số, lớp lưới/safe-zone, trước/sau, xem thử 5s.
6. **Khu Tuỳ chọn** — form sinh từ schema theo tab, tooltip, ↺ mặc định.
7. **Khu Chạy** — pre-flight list, tiến trình tổng + worker, log ảo hoá + lọc, tạm dừng/dừng, hoàn tất + chạy lại lỗi, banner job dở.
8. **Quản lý preset** — menu, lưu/lưu thành/nhân bản/đổi tên/xoá/xuất/nhập, dấu chưa lưu, Ctrl+S, beforeunload.
9. **Kiểm tra UI** — Playwright smoke (`tests/ui`), chụp 2 theme × 3 kích thước, checklist ui-ux-pro-max.
